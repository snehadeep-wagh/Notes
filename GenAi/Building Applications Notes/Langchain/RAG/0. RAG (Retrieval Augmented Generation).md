
RAG is a technique that connects an LLM to an external, private knowledge base to provide context for generating accurate, grounded responses.

- **Key Benefits:** 
	- Access to up-to-date info
	- Enhanced data privacy 
	- Ability to process documents of unlimited size by splitting them into chunks.
	
- **The 4 Core Components of RAG:** 
	- Document Loaders
	- Text Splitters
	- Vector Databases
	- Retrievers.

# Why do we need RAG?

Imagine ChatGPT was trained until 2025.

Now you ask:

> "What is my company's leave policy?"

ChatGPT has no idea.

But your company has a PDF called:

```
leave_policy.pdf
```

RAG allows the AI to:

1. Search the PDF
2. Find the relevant section
3. Give an answer

Without retraining the model.
