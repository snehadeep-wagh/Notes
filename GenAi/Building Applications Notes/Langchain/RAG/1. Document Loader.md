
**What are Document Loaders?**
Document Loaders are utilities used to fetch data from various sources (PDFs, URLs, Databases, Cloud) and convert it into a **standardized format** called a **Document Object**.

**Standardized Document Schema:**
- **page_content**: The actual text content of the file.
- **metadata**: Contextual info like the source file name, page number, creation date, etc.

**3. Working with Specific Loaders**

**A. Text Loader**

The simplest loader used for processing `.txt` files.
**How it works:** It takes the file path and an optional encoding (e.g., `utf-8`) and returns the entire file as a single Document object inside a list.

Limitation: 
	Works only with .txt


```
from langchain_community.document_loaders import TextLoader

# Initialize with file path and encoding
loader = TextLoader("cricket.txt", encoding="utf-8")
docs = loader.load() # Returns a list of Document objects

print(docs.page_content)
print(docs.metadata)
```

---

**B. PyPDF Loader**

Used for searchable PDF files. It creates one Document object per page.

- **Prerequisite:** `pip install pypdf`.
- **Limitation:** Not recommended for scanned or highly complex image-based PDFs.

This is the standard loader for searchable PDF files.

- **Key Feature:** It works on a **page-by-page basis**. If a PDF has 23 pages, this loader creates a list of 23 Document objects.
- **Metadata:** Automatically includes the page number and source file in the metadata.
- **Note:** For scanned images or tables, you might need advanced loaders like `UnstructuredPDFLoader` or `PDFPlumberLoader`


```
from langchain_community.document_loaders import PyPDFLoader

loader = PyPDFLoader("curriculum.pdf")
docs = loader.load()

print(f"Total Pages: {len(docs)}")
print(docs.page_content)
```

**C. Directory Loader**

Loads multiple files from a folder using glob patterns.
Used to load multiple files from a specific folder simultaneously.

- **Parameters:** You specify the directory path, a `glob` pattern (e.g., `"**/*.pdf"`), and the `loader_cls` (which class to use to load those files).

```
from langchain_community.document_loaders import DirectoryLoader, PyPDFLoader

# Load all PDF files in the 'books' folder
loader = DirectoryLoader(
    "./books", 
    glob="**/*.pdf", 
    loader_cls=PyPDFLoader
)
docs = loader.load()
```

**4. Eager Loading vs. Lazy Loading**

Choosing the right loading method depends on your data size and hardware constraints.
![[Pasted image 20260731031448.png]]

|Feature|`load()` (Eager)|`lazy_load()`|
|---|---|---|
|**Execution**|Loads all documents into RAM at once.|Loads one document at a time on-demand.|
|**Return Type**|Python List of Documents.|Python Generator.|
|**Use Case**|Small datasets/files.|Massive datasets/low memory systems.|

**Lazy Loading Code Example:**

```
# Rather than waiting for 1000 files to load, process them in a loop
for doc in loader.lazy_load():
    print(doc.metadata) 
    # Process and remove from memory immediately
```

**5. Web and Data Table Loaders**

**A. WebBaseLoader**

Scrapes content from static HTML web pages using `BeautifulSoup`.

- **Limitations**: Doesn’t handle JavaScript-heavy pages well (use SeleniumURLLoader for that). • Loads only static content (what's in the HTML, not what loads after the page renders).

- Loads and extracts text content from web URLs.

- **How it works:** It uses the `requests` library to fetch HTML and `BeautifulSoup` to strip tags and extract visible text.
- **Flexibility:** You can pass a single URL string or a **list of URLs** to load multiple pages at once.

```
from langchain_community.document_loaders import WebBaseLoader

loader = WebBaseLoader("https://example.com/product")
docs = loader.load()
```

**B. CSV Loader**

Ideal for data analysis tasks. It creates one Document object for every single row in the CSV file.
- **Workflow:** By default, it creates **one Document object for every single row** in the CSV file.
- **Content:** The `page_content` format looks like a string of `ColumnName: Value` pairs.

```
from langchain_community.document_loaders import CSVLoader

loader = CSVLoader("data.csv")
docs = loader.load()

# Access content of the first row
print(docs.page_content) 
```

**7. Custom Document Loader**

To create your own loader, you must follow a specific structural template to ensure it remains compatible with other LangChain components like splitters and vector stores:

1. **Inheritance:** You must create a Python class that inherits from the **BaseLoader** class.
2. **Custom Logic:** You define how the data is fetched within the **load()** method (for bringing everything into memory at once) or the **lazy_load()** method (for processing large datasets one piece at a time).
3. **Document Standardization:** Your custom logic must package the fetched data into **Document objects**. As we discussed, every Document object must contain `page_content` (the actual text) and `metadata` (contextual info like the source name).

**Python Example: A Custom API Loader**

Here is a skeleton of how you would implement a custom loader to fetch data from a hypothetical internal company API:

```
from langchain_core.document_loaders import BaseLoader
from langchain_core.documents import Document

class MyInternalAPILoader(BaseLoader):
    def __init__(self, api_url: str):
        self.api_url = api_url

    def load(self):
        # 1. Your custom logic to fetch data (e.g., using requests)
        # For example purposes, we'll simulate a response
        fetched_text = "Standard Operating Procedure: All employees must..."

        # 2. Return the data as a list of Document objects
        return [
            Document(
                page_content=fetched_text, 
                metadata={"source": self.api_url, "type": "Internal SOP"}
            )
        ]
```
