
**Runnables** are the standardized building blocks of LangChain that allow different components like prompts, models, and parsers to be "piped" together into seamless pipelines,. By inheriting from a common abstract class, these components all implement the `.invoke()` method, ensuring they follow a consistent set of rules for communication.

The tutorial divides Runnables into two categories: **Task-Specific Runnables** (like `ChatOpenAI` or `PromptTemplate`) and **Runnable Primitives**, which serve as the orchestration logic

##### **1. RunnableSequence**

This primitive executes runnables in a linear chain, where the output of one component automatically becomes the input for the next. It is used to standardize how different components—like prompts, models, and parsers—communicate through the `.invoke()` method.

**Example Code: Sequential Joke Generator**

```
from langchain_openai import ChatOpenAI
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnableSequence

# Define components
prompt = PromptTemplate.from_template("Write a joke about {topic}")
model = ChatOpenAI()
parser = StrOutputParser()

# Create chain using RunnableSequence
chain = RunnableSequence([prompt, model, parser])

# Execute
result = chain.invoke({"topic": "AI"})
print(result)
```

_Note: You can connect an unlimited number of runnables in this manner__._

##### **2. RunnableParallel**

This primitive executes multiple tasks simultaneously using the same initial input. It returns a **dictionary** where each key represents the output of an independent parallel branch.

**Example Code: Multi-Platform Content Creator**

```
from langchain_core.runnables import RunnableParallel

# Two different prompt templates
tweet_prompt = PromptTemplate.from_template("Write a tweet about {topic}")
linkedin_prompt = PromptTemplate.from_template("Write a LinkedIn post about {topic}")

# Parallel execution
parallel_chain = RunnableParallel({
    "tweet": tweet_prompt | model | parser,
    "linkedin": linkedin_prompt | model | parser
})

# One input triggers both tasks independently
result = parallel_chain.invoke({"topic": "Generative AI"})
print(result["tweet"])
print(result["linkedin"])
```

##### **3. RunnablePassthrough**

This primitive returns the input exactly as it received it, without any modification. It is critical when you need to "save" data that would otherwise be overwritten by the next step in a sequence.

**Example Code: Preserving Original Joke with Explanation**

```
from langchain_core.runnables import RunnablePassthrough

# Sequence: Generate Joke -> (Parallel: Pass original joke AND Generate explanation)
joke_chain = prompt | model | parser
explanation_chain = PromptTemplate.from_template("Explain this joke: {text}") | model | parser

final_chain = joke_chain | RunnableParallel({
    "original_joke": RunnablePassthrough(), # Keeps the joke as is
    "explanation": explanation_chain # Generates something new
})

result = final_chain.invoke({"topic": "cricket"})
print(result["original_joke"])
print(result["explanation"])
```

##### **4. RunnableLambda**

This primitive converts any standard Python function into a runnable component. This allows you to inject custom logic, such as word counting or data cleaning, directly into your AI pipeline.

**Example Code: Word Counter Middleware**

```
from langchain_core.runnables import RunnableLambda

# A standard Python function
def word_count(text):
    return len(text.split())

# Convert to Runnable and use in a chain
chain = prompt | model | parser | RunnableLambda(word_count)

# Output will be the integer count of words in the generated joke
print(chain.invoke({"topic": "AI"}))
```

##### **5. RunnableBranch**

This is the "if-else" statement of LangChain. It routes input to different paths based on specific conditions, executing the first branch that evaluates to `True`.

**Example Code: Conditional Summarization**

```
from langchain_core.runnables import RunnableBranch

# Logic: If report > 300 words, summarize it. Otherwise, return the full report.
branch_chain = RunnableBranch(
    (lambda x: len(x.split()) > 300, summary_prompt | model | parser),
    RunnablePassthrough() # Default path
)

final_workflow = report_prompt | model | parser | branch_chain
result = final_workflow.invoke({"topic": "Space Exploration"})
```

##### **LCEL (LangChain Expression Language)**

While classes like `RunnableSequence` are the engine, LCEL is the **declarative syntax**. It uses the pipe operator (`|`) to make code more readable. Instead of writing `RunnableSequence([A, B, C])`, you simply write `A | B | C`.

**Example: Simple Sequential Chain**

This example pipes a prompt into a model and then into a string output parser.

```
from langchain_openai import ChatOpenAI
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 1. Define the modular components
prompt = PromptTemplate.from_template("Tell me a fun fact about {topic}")
model = ChatOpenAI()
parser = StrOutputParser()

# 2. Create the chain using LCEL (the pipe operator)
# Flow: Input -> Prompt -> Model -> Parser -> Final String
chain = prompt | model | parser

# 3. Execute the entire pipeline with one call
result = chain.invoke({"topic": "Space"})
print(result)
```

**Why use LCEL?**

- **Conciseness:** It replaces complex constructors like `RunnableSequence([A, B, C])` with the intuitive `A | B | C` syntax.
- **Automatic Handover:** The output of one component automatically becomes the input for the next.
- **Streaming & Batching:** LCEL chains come with built-in support for streaming and batch processing.
