
### **1. What is an AI Agent?**

Large Language Models (LLMs) are like a "brain" that can reason and speak but lack "hands and legs" to perform real-world tasks like booking tickets or running code.

- **Definition:** An AI agent is an intelligent system that receives a high-level goal and autonomously plans, decides, and executes a sequence of actions using external tools or APIs while maintaining context and adapting to new information.
- **The Travel Agent Example:** If you want to plan a budget trip from Delhi to Goa, a traditional system gives you a form to fill out. An AI Agent, however, understands your intent, researches flights and hotels via APIs, checks your calendar, and asks for your preference on specific options (like 3AC vs. sleeper class) before executing the final booking.

**Core Characteristics of Agents:**

|Characteristic|Description|
|:--|:--|
|**Goal-driven**|You tell it _what_ you want, not _how_ to do it.|
|**Autonomous Planning**|It breaks down complex problems into steps.|
|**Tool-aware**|It knows which tools (search, calculator, API) it has and when to use them.|
|**Adaptive**|If an API fails or information changes, it re-plans its approach.|

### **2. Building an Agent in LangChain**

To build a basic agent, you need three ingredients: an **LLM** (the brain), a **set of tools** (the hands), and a **prompt template** (the instructions).

**Complete Python Implementation:**

````
from langchain_openai import ChatOpenAI
from langchain_community.tools.ddg_search import DuckDuckGoSearchRun
from langchain.agents import create_react_agent, AgentExecutor
from langchain import hub

# 1. Initialize the Reasoning Engine (LLM)
llm = ChatOpenAI(model="gpt-4o")

# 2. Define the Tools (The Agent's "hands")
search_tool = DuckDuckGoSearchRun()
tools = [search_tool]

# 3. Pull a Pre-defined Agent Prompt from LangChain Hub
# This prompt guides the LLM to follow the ReAct logic.
prompt = hub.pull("hwchase17/react")

# 4. Construct the Agent
agent = create_react_agent(llm, tools, prompt)

# 5. Create the Executor to run the Agent
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# 6. Execute a Goal
agent_executor.invoke({"input": "What is the current population of France?"})
````

### **3. The ReAct Design Pattern**
**ReAct** stands for **Reasoning + Acting**. It is the specific design pattern that allows an LLM to "think" before it "acts".
*   **The Logic:** Instead of generating an entire answer at once, the model follows a loop: **Thought \\(\rightarrow\\) Action \\(\rightarrow\\) Action Input \\(\rightarrow\\) Observation**.
*   **Agent Scratchpad:** This is the agent's short-term memory. After every tool call, the result (observation) is added to this scratchpad and sent back to the LLM so it can decide the next step.

    *   **Observation:** Paris.
    *   **Thought:** Now I need the population of Paris. (Loop continues until final answer is found).

### **4. Agent vs. Agent Executor**
It is vital to distinguish between these two components, as they work together to close the loop.

*   **The Agent:** This is the decision-maker. It takes the user query and the scratchpad to generate an **AgentAction** (which tool to use) or an **AgentFinish** (the final answer).
*   **The Agent Executor:** This is the runtime that "does the heavy lifting". It receives the agent's decision, actually runs the Python code for the tool, collects the result, and feeds it back into the loop.

### **5. The Agent Execution Flow Chart**
The workflow follows a continuous cycle until the goal is achieved:

1.  **Input:** User enters a query.
2.  **Prompting:** Executor passes the query and the current **Agent Scratchpad** (which tracks progress) to the Agent.
3.  **Reasoning:** The LLM (Agent) generates a **Thought** and decides on an **Action**.
4.  **Action Object:** An `AgentAction` object is created containing the tool name and inputs.
5.  **Execution:** The Executor runs the specified tool and gets an **Observation** (result).
6.  **Update:** The Observation is appended to the **Scratchpad**.
7.  **Termination:** The loop repeats until the LLM generates an `AgentFinish` object containing the **Final Answer**.
