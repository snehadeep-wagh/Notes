#### **Understanding Temperature**

- **Temperature = 0:** The model becomes **deterministic**. The same input will consistently produce the same output.
- **Temperature = 1.5 - 2:** The model becomes **creative**. The same input will produce different, more varied responses each time.
- **Use Case:** Use low temperature for factual tasks (e.g., data extraction) and high temperature for creative tasks (e.g., poetry).

---

#### **2. Static vs. Dynamic Prompts**

A **Prompt** is the instruction or query sent to an LLM to guide its output.

- **Static Prompts:** These are hardcoded strings written by the programmer. They are risky for real-world apps because they give users too much control, which can lead to spelling errors, inconsistent formatting, or model hallucinations.
- **Dynamic Prompts:** These use **Prompt Templates** with placeholders (e.g., `{topic}`). The developer controls the "frame" of the prompt, while the user only provides specific variables, ensuring a consistent user experience.

---

#### **3. PromptTemplate Class**

The `PromptTemplate` class allows you to create structured, reusable prompts.

**Python Example: Research Assistant**

This code creates a dynamic prompt that summarizes a research paper based on user-selected criteria.

```
from langchain_core.prompts import PromptTemplate

# 1. Define the template with placeholders
template = """
Please summarize the research paper titled "{paper_input}" 
with the following specifications:
Explanation Style: {style_input}
Explanation Length: {length_input}
Ensure the summary is clear and includes mathematical details if present.
"""

# 2. Create the PromptTemplate object
prompt_template = PromptTemplate(
    input_variables=["paper_input", "style_input", "length_input"],
    template=template,
    validate_template=True #This is used for validation if the input_variables are not added correctly.
)

# 3. Fill the placeholders and invoke
formatted_prompt = prompt_template.invoke({
    "paper_input": "Attention Is All You Need",
    "style_input": "Beginner-Friendly",
    "length_input": "Medium"
})

print(formatted_prompt.text)
```

### **Why use PromptTemplate over f-strings?**

##### 1. **Validation:** 
It automatically checks if all required placeholders are filled before sending the prompt to the LLM.
##### 2. **Reusability:** 
**You can save templates as `.json` files and load them into different parts of your application.** 
**1. Saving the Template as JSON**

To save a template, you use the `.save()` method on a `PromptTemplate` object. This is useful for keeping your main application code clean and making templates reusable across different parts of a project.

```
from langchain_core.prompts import PromptTemplate

# Define your template with placeholders
template_str = """
Please summarize the research paper titled "{paper_input}" 
with the following specifications:
Explanation Style: {style_input}
Explanation Length: {length_input}
"""

# Create the PromptTemplate object
prompt_template = PromptTemplate(
    input_variables=["paper_input", "style_input", "length_input"],
    template=template_str
)

# Save the template as a JSON file
prompt_template.save("template.json")
```

**2. Loading and Using the JSON Template**

Once saved, you can use the `load_prompt` function to bring the template back into any script. The sources note that once loaded, the template works exactly like one defined directly in the code.

```
from langchain_core.prompts import load_prompt

# Load the template from the JSON file
loaded_template = load_prompt("template.json")

# Fill the placeholders and invoke the template
formatted_prompt = loaded_template.invoke({
    "paper_input": "Attention Is All You Need",
    "style_input": "Technical",
    "length_input": "Short"
})

# Access the formatted string
print(formatted_prompt.text)
```

**Why use this approach?**

- **Modularity:** It prevents your main code files from becoming "bulky" with large text blocks.
- **Reusability:** Multiple files or web pages in a large application can import the same `.json` template, ensuring consistency.
- **Validation:** Unlike standard Python f-strings, `PromptTemplate` automatically validates that all required variables are present before execution.

##### 3. **Ecosystem Integration:** 
They are designed to work seamlessly with LangChain **Chains**.

#### **4. LangChain Message Types**

When building chatbots, simply sending a list of strings is insufficient because the LLM needs to know **who** said **what** to maintain context. LangChain provides three core message classes:

- **SystemMessage:** Sets the behavior/role of the AI (e.g., "You are a helpful doctor").
- **HumanMessage:** Represents the user's input.
- **AIMessage:** Represents the model's response.

---

**5. ChatPromptTemplate**

While `PromptTemplate` is for single-turn strings, `ChatPromptTemplate` is used for **multi-turn conversations** involving a list of messages.

**Python Example: Dynamic Chat Template**

The instructor recommends using the tuple syntax for clarity and compatibility with newer LangChain versions.

```
from langchain_core.prompts import ChatPromptTemplate

# Create a template for a conversation
chat_template = ChatPromptTemplate([
    ("system", "You are a helpful {domain} expert."),
    ("human", "Explain the concept of {topic} in simple terms.")
])

# Fill the template
prompt = chat_template.invoke({
    "domain": "Cricket",
    "topic": "Leg Before Wicket (LBW)"
})

print(prompt.to_messages())
```

**6. MessagesPlaceholder**

A `MessagesPlaceholder` is a specialized tool used to **dynamically insert chat history** into a prompt template at runtime. This is crucial for applications that need to load previous conversations from a database or file to provide context for a new query.

**Python Example: Customer Support with History**

In this scenario, we load a user's past refund request history before asking a new question.

```
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.messages import HumanMessage, AIMessage

# 1. Define template with a placeholder for history
chat_template = ChatPromptTemplate([
    ("system", "You are a helpful customer support agent."),
    MessagesPlaceholder(variable_name="chat_history"),
    ("human", "{query}")
])

# 2. Simulated history loaded from a database/file
history = [
    HumanMessage(content="I want to request a refund for order 12345."),
    AIMessage(content="Your refund has been initiated and will take 3-5 days.")
]

# 3. Invoke with both the history and the new query
final_prompt = chat_template.invoke({
    "chat_history": history,
    "query": "Where is my refund?"
})

# The model now sees the system role, the past history, and the new question
print(final_prompt.to_messages())
```
