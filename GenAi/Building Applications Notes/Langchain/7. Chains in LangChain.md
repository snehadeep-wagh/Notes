
**Chains** are the orchestration layer of LangChain, allowing you to connect modular steps like prompts, models, and parsers into a single automated pipeline. Instead of manually executing each step, the output of one component automatically becomes the input for the next using **LCEL (LangChain Expression Language)** and the pipe operator (`|`).

---


#####  **1. Core Concept: Why Chains?**

- **The Problem:** Building LLM apps manually requires individual calls for prompts, models, and parsers, which becomes unmanageable as complexity grows.
- **The Solution:** Chains act as a **pipeline**. Once triggered, the entire sequence executes automatically, moving data from the first component to the last without manual intervention.


---

##### **1. Simple Sequential Chains**

The most basic chain executes tasks in a linear series.

**Example:** Taking a topic and generating five facts.

```
from langchain_openai import ChatOpenAI
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 1. Components
prompt = PromptTemplate.from_template("Generate 5 facts about {topic}")
model = ChatOpenAI()
parser = StrOutputParser()

# 2. Linear Chain (LCEL)
chain = prompt | model | parser

# 3. Execution
print(chain.invoke({"topic": "Cricket"}))
```

- **Key Note:** You can visualize the flow using `chain.get_graph().print_ascii()`.

---

#####  **2. Complex Sequential Chains**

These involve multiple LLM calls where the output of the first model (e.g., a long report) is passed into the prompt for a second model (e.g., to create a summary).

**Example:** Report → Summary.

```
prompt1 = PromptTemplate.from_template("Write a report on {topic}")
prompt2 = PromptTemplate.from_template("Summarize this: {text}")

# First parser output feeds into second prompt
chain = prompt1 | model | parser | prompt2 | model | parser

result = chain.invoke({"topic": "AI in Medicine"})
```

---

#####  **3. Parallel Chains**

Using **RunnableParallel**, you can execute multiple tasks simultaneously from the same input, which is much faster than running them one by one.

**Example:** Generate notes and a quiz from the same text simultaneously.

```
from langchain_core.runnables import RunnableParallel

# Define two separate chains
notes_chain = prompt1 | model1 | parser
quiz_chain = prompt2 | model2 | parser

# Combine them in parallel
parallel_chain = RunnableParallel({"notes": notes_chain, "quiz": quiz_chain})

# Final output is a dictionary containing both results
result = parallel_chain.invoke({"text": "Deep Learning is..."})
```

---

##### **4. Conditional Chains**

Using **RunnableBranch**, you can implement "if-else" logic. The chain analyzes an input and routes it to different paths based on a condition.

**Example:** Route customer feedback based on sentiment.

```
from langchain_core.runnables import RunnableBranch

# Branching logic: (condition, chain_to_run)
branch_chain = RunnableBranch(
    (lambda x: x["sentiment"] == "positive", positive_response_chain),
    (lambda x: x["sentiment"] == "negative", negative_response_chain),
    default_chain # Executed if no conditions match [14]
)

# Combined with a classifier
final_chain = classification_chain | branch_chain
```

- **Pro Tip:** Use **Pydantic** with your classifier to ensure the sentiment output is always a consistent string like "positive" or "negative" so the branch doesn't break.
