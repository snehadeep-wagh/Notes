
#### **What is Agentic AI?

Agentic AI is a software paradigm where a system is given a goal and independently determines how to achieve it with minimal human guidance.

- **Core Definition:** A type of AI that plans, takes action, adapts to changes, and only seeks help when necessary.
- **Reactive vs. Proactive:**
    - **Generative AI (Reactive):** Responds to specific prompts (e.g., "Find a flight to Goa") without taking further initiative.
    - **Agentic AI (Proactive):** Given a goal (e.g., "Plan a trip to Goa"), it independently researches flights, books hotels, and creates an itinerary.

#### **2. Example: The AI HR Recruiter**

The video uses an HR scenario to illustrate an agent's workflow:

1. **The Goal:** Hire a backend engineer with 2-4 years of experience.
2. **The Plan:** Draft a Job Description (JD), post it to LinkedIn/Naukri, monitor applications, screen candidates, schedule interviews, and handle onboarding.
3. **Autonomous Execution:** The agent accesses company documents for JD requirements, uses APIs to post jobs, and analyzes resumes without constant human prompts.

#### **3. Key Characteristics**

An Agentic AI system is identified by six specific traits:

|Characteristic|Description|
|---|---|
|**Autonomy**|Ability to make decisions and take actions without step-by-step instructions.|
|**Goal Oriented**|Operates with a persistent objective in mind.|
|**Planning**|Breaking high-level goals into a structured sequence of sub-goals.|
|**Reasoning**|Interpreting information and drawing conclusions to make decisions.|
|**Adaptability**|Modifying strategies in response to unexpected conditions.|
|**Context Aware**|Retaining relevant information from past tasks and environment.|

---

#### **4. Deep Dive: Autonomy**

Autonomy means the system is proactive rather than reactive.

- **Types of Autonomy:** Found in execution (carrying out steps), decision-making (shortlisting candidates), and tool usage (deciding when to use a specific API).
- **Controlling Autonomy:** Necessary to prevent risks like incorrect salary offers or biased hiring.
    - **Permissions:** Limiting tool scope.
    - **Human in the Loop:** Requiring human approval for high-risk actions (e.g., sending an offer letter).
    - **Override Controls:** Allowing users to pause or stop the agent.
    - **Guardrails:** Hard rules (e.g., "No interviews on weekends").

---

#### **5. Goal Oriented**

The goal acts as a "compass" for the agent's autonomy. Goals can be independent or have constraints (e.g., "Hire a candidate _from India_").

**Conceptual Python Representation (JSON Structure):** The agent stores the goal and its progress in memory:

```
{
  "main_goal": "Hire a Backend Engineer",
  "constraints": {
    "experience": "2-4 years",
    "remote": True,
    "stack": ["Python", "AWS"]
  },
  "status": "Active",
  "progress": {
    "jd_drafted": True,
    "posted_on": ["LinkedIn", "Naukri"],
    "applicants_screened": 8,
    "interviews_scheduled": 2
  }
}
```

---

#### **6. Planning**

Planning is a two-step iterative process: Creating a plan and then executing it.

1. **Candidate Plans:** The agent views planning as a "search problem," generating multiple paths to reach the goal.
2. **Evaluation:** It assesses plans based on efficiency, tool availability, cost, risk, and constraints.
3. **Selection:** Choosing the best plan via pre-programmed policy or human input.

---

#### **7. Reasoning**

Reasoning is the cognitive process used in both planning and execution.

- **In Planning:** Used for goal decomposition and resource estimation.
- **In Execution:** Used for tool selection (e.g., "I need Google Search to find salary benchmarks") and error handling (e.g., "LinkedIn is down; I should notify the human").

---

#### **8. Adaptability**

The ability to modify actions while staying aligned with the goal.

- **Triggers for Adaptation:** Tool failures, external feedback (e.g., low applicant volume), or mid-way goal changes.

---

#### **9. Context Awareness**

This is implemented through **Memory**.

- **Short-term Memory:** Current session info (e.g., "Candidate B has 3 years of experience").
- **Long-term Memory:** High-level goals, past interactions, and guardrails.

---

#### **10. Components of Agentic AI**

Most systems consist of these five high-level components:

1. **Brain (LLM):** Interprets goals, plans, reasons, and handles communication.
2. **Orchestrator:** The "nervous system" that executes the plan, handles routing, and retries (e.g., LangGraph).
3. **Tools:** The "hands and legs" of the agent—APIs, databases, and knowledge bases used to interact with the world.
4. **Memory:** Tracks the state, session history, and long-term preferences.
5. **Supervisor:** Manages human-in-the-loop interactions, approvals, and escalations.
