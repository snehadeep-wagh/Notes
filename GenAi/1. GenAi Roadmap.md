
**Core Concepts & Definitions**

- **Generative AI:** A type of AI that creates **new content** (text, images, music, or code) by learning patterns from existing data, effectively mimicking human creativity.
- **AI Landscape:** GenAI is a subset of **Deep Learning**, which is a subset of **Machine Learning**, all falling under the broader umbrella of **Artificial Intelligence**.
- **Foundation Models:** These are the **backbone of GenAI**. They are large-scale, generalized models (like **LLMs** for text or **LMMs** for multimodal data) trained on massive amounts of data and hardware to perform multiple types of tasks rather than just one specific task.

---

**The Two-Part Curriculum**

**1. The Builder's Perspective (Building Models)**

This side focuses on the technical process of creating and deploying foundation models.

- **Prerequisites:** Mastery of Machine Learning and Deep Learning fundamentals, and familiarity with frameworks like **PyTorch** or TensorFlow.
- **Transformer Architecture:** The starting point for all modern foundation models. You must understand self-attention, encoders, decoders, and embeddings.
- **Types of Transformers:** Learning different architectures like **BERT** (Encoder-only) and **GPT** (Decoder-only).
- **Pre-training:** Training a model from scratch using massive datasets, involving tokenization strategies and distributed training.
- **Optimization:** Techniques like **Quantization** and **Knowledge Distillation** to make large models run on standard hardware.
- **Fine-tuning:** Adjusting a generalized model for specific tasks using techniques like **RLHF** (Reinforcement Learning from Human Feedback) or **PEFT**.
- **Evaluation & Deployment:** Using leaderboards and metrics to test performance before deploying the model for public use.

**2. The User's Perspective (Building Applications)**

This side involves using pre-built models to create software and tools.

- **Basic App Development:** Learning to use **APIs** for closed-source models or libraries like **Hugging Face** and **Ollama** for open-source models. Frameworks like **LangChain** are essential here.
- **Improving Output:**
    - **Prompt Engineering:** The art of refining inputs to get better responses from the model.
    - **RAG (Retrieval Augmented Generation):** Connecting an LLM to private or external data to provide specific answers.
    - **Fine-tuning:** Performing "shallow" fine-tuning at the user level to customize model behavior.
- **AI Agents:** Building systems where a chatbot can use **tools** (e.g., booking a hotel or searching the web) to perform actions beyond just talking.
- **LLMOPs:** The operational side of managing, evaluating, and deploying LLM-based applications in production.

**The Role of an AI Engineer**

An **AI Engineer** is a professional who bridges these two worlds. While a software developer can build applications using the User's perspective, a high-value AI Engineer understands the Builder's side (how models work internally) to build more efficient and powerful applications.
